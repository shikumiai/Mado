# 競合比較ベンチマーク（業種別 10 サイト）

> 採点者の主観ブレを潰すための「比較対象」。スコアリング時に必ずここから 10 サイトを引いて、上回る・下回るを 3 つずつ書く。

## 使い方

1. 顧客の業種を特定（建築 / 美容 / 飲食 / 医療 / 教育 / 小売 / 士業 / その他）
2. その業種の 10 サイトを開く（タブ 10 個）
3. 該当機能を 10 サイト全部で確認
4. 採点対象の実装と比較し「上回る点 3 つ」「下回る点 3 つ」を箇条書き
5. 上回るが多ければ高得点、下回るが多ければ低得点

「主観でいい感じ」は禁止。必ず数えて書く。

## 比較記述テンプレート（採点時に必ず書く）

```markdown
## 競合比較

### 採点者の立場
私は {年齢}{性別} の {状況}。{目的} でこのサイトを訪れた。

### 上回る点 3 つ
1. {具体的な数字・実装}（他 N 社は {対比}）
2. ...
3. ...

### 下回る点 3 つ
1. {具体的な弱点}（{ベンチサイト名} は {良い実装}）
2. ...
3. ...

### 判定根拠
上回る数 - 下回る数 = {N} 件のアドバンテージ。
スコア{値} はこの差に基づく。
```

**書かない採点は無効。**「いい感じ」「悪くない」は減点理由になる。
