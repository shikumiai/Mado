# テンプレート写真の指示書（PHOTO_BRIEF）

> 2026-09-09 / 正は `docs/TEMPLATE_SYSTEM_V3.md` 8.1。ファイル名と枚数のコードの正は `src/lib/templates/photos.ts`。
> ここは「そのファイルに何を写すか」を1行ずつ決めた表。文章（デモの会社名・住所・品書き・実績名）と写真が食い違わないようにするためのもの。

## 0. 全部に共通のこと

- **置き場**: `public/images/templates/<テンプレートID>/<ファイル名>`。置けばそのまま画面に出る（コードは触らない）。まだ無いファイルは自動で線画（art.tsx）に戻るので、途中まででも壊れない。
- **寸法**: 横位置 **1536×1024**（hero / scene / work / item）、縦位置 **1024×1536**（owner / staff）。
- **作り**: 写真調（イラスト・CG・合成っぽさは禁止）。**日本の実景**、自然光、35mm相当、彩度控えめ。同じテンプレートの中は光と色調をそろえる。
- **写さない**: 読める看板・商標・ロゴ・人の名札・ナンバープレート・雑誌の表紙。文字が写ると、お客さんが自分の写真に差し替えるまで別の会社の名前が出てしまう。
- **人**: 日本人。年齢と役どころは各行に書いたとおり。カメラ目線でなくてよい（仕事の手元を見ている姿のほうが合う）。
- **色**: テンプレートの色（`--tpl-*`）と喧嘩しない中間色を基調に。原色の面積を大きく取らない。
- **枚数**: 1テンプレートあたり **11枚**（`hero` / `scene-1` / `scene-2` / `work-1`〜`work-4` / `owner` / `staff-2` / `staff-3` / `team`）。品書きに写真を出す5業種（saveur・velvet・beacon・forge・marche）は `item-1`〜`item-4` を足して **15枚**。合計 **130枚**。
- **上限の決まり**: 実績は4件まで、人は3人まで（1人目は `owner.jpg`）、品書きの写真は4品まで。デモの一覧もこの数に合わせてあるので、初期状態で写真の入らない行は出ない。同じ写真が1つの並びに二度出ることもない。
- **お知らせに写真は使わない**: 10業種とも、写真の出ない見せ方（一覧行・静寂）にしてある。`news-*.jpg` は作らない。
- **優先順**: 各テンプレートの【まず作る】が初期状態で実際に画面に出るもの。【あとで】は見せ方（variant）を替えたとき・部品を足したときに出る予備なので後回しでよい。
