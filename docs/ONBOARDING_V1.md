# 公開したあと — 新規ユーザーがやること

> 2026-09-15 決定（Lyo）。対象は `/start` で公開ボタンを押した直後から、
> サイトが「自分の会社のもの」になるまで。

## 1. 目的

公開ボタンを押した人が、**次にやることを迷わず1つずつ終えて、自分の会社のサイトにできる**。

守る約束は2つ。

- 公開した初日から、人に見せられる見た目になっている
- 写真を入れる以外の判断（並び・配色・文章の型）は本人にさせない

## 2. いまの状態（2026-09-15 時点の事実）

| | 申込中に見ているもの | 実際に公開されるもの |
|---|---|---|
| 会社名 | 入力した社名 | 入力した社名 |
| キャッチコピー | 業種見本の一文 | 空 |
| 施工実績（画面上は「必須」） | 6件・写真つき | 0件 |
| 選ばれる理由 | 3つ | 0件 |

`generateSiteConfig` が `projects: []` `strengths: []` で作るため、
中身が0件のセクションは描画側で `null` を返して**セクションごと消える**。
申込中の見本と公開物が一致していない。

公開後の着地は `/app` のサイト一覧。「サイトを見る」「編集する」が並ぶだけで、
次に何をするかは書かれていない。

## 3. 決めたこと

### 3-1. 見本の中身を入れたまま公開する（A）

公開する `site.config.json` に、業種見本の中身を最初から入れる。
部品を足したときに使っている `sampleSectionSeed` と同じものを、初期生成でも使う。

- 会社名・メール・電話など**本人が入力した項目は見本で上書きしない**（`COMPANY_BACKED` の既存判定をそのまま使う）
- 写真は `TEMPLATE_PHOTOS` のもの。差し替えるまではこれが出る

### 3-2. 見本のままの箇所を、本人にだけ見せる

公開サイトには何も出さない。ログイン中の画面にだけ「まだ見本のままの箇所」を出す。

判定は**印を持たせず、突き合わせで行う**。
`sampleSectionData` からその業種の見本をもう一度作り、いまの値と一致していれば見本のまま。
`site.config.json` に `sample: true` のような項目は足さない（設計を汚さないため）。

### 3-3. 着地は「次にやること1つ」（B）

公開直後は、いま何をすればいいかが1つだけ出ている画面に着く。
やることを全部並べるのはやめる。1つ終わると次の1つが出る。

順番（上にあるものほど、直したときにサイトの印象が大きく変わる）:

1. メインの写真を自分のものにする
2. キャッチコピーを自分の言葉にする
3. 施工実績を1件、自分のものにする
4. 会社概要（住所・電話・営業時間）を入れる
5. 残りの写真を入れる

各項目には「直す」ボタンが1つ。押すと編集画面の該当箇所へ直行して、その場所が光る。

### 3-4. 写真は本人が入れる（全プラン共通）

写真の差し替えは、おためしもおまかせも**本人が自分で行う**。
だから操作は1画面にまとめ、判断をさせない。

- 必要な枠（メイン・実績1〜4・代表…）が並び、それぞれに見本が入っている
- 枠を押す → 端末から選ぶ → その場で入れ替わる
- 大きさ・切り抜きはこちらで合わせる。本人に数値を触らせない
- スマホからの操作を前提にする（パソコン操作不要と言っているため）

プランの差は、AI編集の回数と使える部品の数で表す。写真の入れ方は全プラン同じにする。

## 4. 画面

| 画面 | 役割 |
|---|---|
| `/app`（公開直後） | 完成度と「次にやること」1つ。終わるまでここが入口 |
| 写真をまとめて入れる | 枠と見本が並び、押して選ぶだけ |
| 編集画面 | 「直す」から該当箇所へ直行。既存の部品組み立てはそのまま |

## 5. 実装の順番

1. `generateSiteConfig` に見本を入れる（3-1）— 空セクション消失もこれで直る
2. `src/lib/onboarding.ts` — 設定を読んで「次にやること」を返す関数（3-2 の突き合わせを含む）
3. `/app` に完成度と次の1つを出す（3-3）
4. 写真をまとめて入れる画面（3-4）

## 6. 合格条件

- 申込から公開まで通したとき、**公開されたサイトが申込中の見本と同じ見た目**になる
- 公開直後の画面に、やることが**1つだけ**出ている
- 写真の差し替えがスマホで、枠を押して選ぶだけで終わる
- 見本のままの箇所が、本人の画面にだけ出る（公開サイトには出ない）
