# LPプレビューの見切れ修正

- 作業ID: mado-lp-previews-20260920
- 担当: Codex / 状態: 実装中
- 場所: `.verification/lp-previews` / ブランチ: `codex/mado-lp-previews`
- 比較元: `bf3a96fbda7517f9845b796e0418472958a33d45`
- 依頼: LPの全プレビューが見切れる不具合の修正・本番反映。
- 原因: 固定倍率で拡縮したiframeを、それより小さい固定サイズの枠に配置。実機では幅約513pxの枠に約717pxの画面が入っていた。
- スマホの実測で、ヒーローの暗黙のgrid列が最小コンテンツ幅まで広がる別の見切れも発見。明示的な1列と子要素のmin-width:0で画面内に収める。
- 変更: 共通LazyIframeが自身の幅から倍率を計算。LPの枠も同じ縦横比で伸縮し、4つすべての描画領域を1280×1120に統一。業種一覧の既存可変高さプレビューも維持。
- 検証予定: lint・型チェック・build、Vercelプレビューと本番で4つの表示、320/390/768/1280px幅、業種一覧の共通部品への影響。
- レビュー: 表示サイズだけの小さな修正のため、差分の自己確認とブラウザ検証で判定する。認証・課金・DBの変更なし。他担当のTASK.mdは変更しない。
