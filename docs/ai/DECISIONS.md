## 2026-09-17: 画像比較から顧客導線へ
- 新規は紹介ページ→問い合わせを対象にする。旧画像注文は別テーブル・旧URLのまま保持。

## 2026-09-18 — 入口をホームページ作成（rebuild-v2）に戻し、導線チェックを有料機能として中に入れる
- 決めたこと: Lyo の判断。本番の入口は rebuild-v2 のホームページ作成。Codex が 9/16 に本番へ出した導線チェック（/pilot）は、入口から外してコードと DB は残す。導線チェックは docs/FUNNEL_CHECK_V1.md の設計で作り直し、おまかせ以上の機能にする。おためしはサイト内チェックのみ。
- 理由: 本業がある運営者が、1件ごとに人の手配と手作業が要る商売を入口にすると、売れるほど詰まる。ホームページ作成は本人が自分で作るので運営の時間を使わない。導線チェックは「作ったあとの道」を見せる追加メニューとして噛み合い、客の獲得もホームページ作成の利用者から始められる。
- 捨てた案: Codex 版を本番に残したまま rebuild-v2 を待つ案（その間、申込が止まったまま）。人3名を手配する手動運用を商品にする案。
- 影響するファイル: next.config.ts（/start→/pilot の転送を外す）、src/proxy.ts（/api/checkout の 410 を外す）、src/app/opengraph-image.tsx（切替前の版へ）、src/app/auth/callback/route.ts（会社がある人は /app、無い人は /start）、docs/FUNNEL_CHECK_V1.md（新設）
- 運転の約束: 決定はこのファイルに書く。本番への merge とデプロイは Claude Code の担当に一本化する。Codex に本番を触らせるときは、その作業票に「本番へ出してよい」と明記する。
