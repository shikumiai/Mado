Mado 公開セットアップ

GitHub・Vercel・エックスサーバー・Google Cloud・Supabase の5つを、 依存関係の順につないで mado.shikumiai.com を公開状態にするまで。

順番を守る理由

ドメインが繋がる前に OAuth 同意画面を公開しようとすると、URL の登録で弾かれます。 Google は「承認済みドメイン」に実在するドメインを求めるためです。 同じ理由で、Vercel のプロジェクトはドメインを足す前に用意しておく必要があります。 下の 1 → 7 は、その依存関係の順に並べてあります。飛ばすと手戻りします。

Vercel のアカウントとドメインは無関係です。 shikumiai.com の DNS はエックスサーバーにあるので、CNAME はどの Vercel アカウントにも向けられます。 つまりアカウントの選び方に制約はありません。

GitHub を Shikumiai アカウントに移す

116 コミットは全部ローカルにあります。新しいリポジトリへ push すれば丸ごと移ります。

先に今日の変更をコミットしてください。 未コミットが 140 件あります。この状態でリネームしても消えはしませんが、 区切りを作っておくと後で戻せます。
ターミナル（USERNAME は Shikumiai の GitHub 名に置き換え）
git remote set-url origin https://github.com/USERNAME/mado.git
git push -u origin main
git remote -v
移管（Transfer）ではなく新規作成で足ります。 116 コミットは全部手元の .git に入っているので、push すればそのまま移ります。 Issue も PR も付いていないリポジトリなので、移管の手間をかける利点がありません。
旧リポジトリ AndoLyo/shikumiya はすぐ消さずに残してください。 新しい側で動くのを見届けてから、最後にまとめて片付けます。

Vercel プロジェクトを作る

ドメインを足す先が要るので、ドメイン作業より先。

変数名値の出どころ

NEXT_PUBLIC_SUPABASE_ANON_KEY同上 anon key
SUPABASE_SERVICE_ROLE_KEY同上 service_role key（NEXT_PUBLIC_ を付けない）
STRIPE_SECRET_KEY.env.local
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY.env.local
STRIPE_WEBHOOK_SECRETまだ空。手順 07 で取る
ANTHROPIC_API_KEY.env.local
NEXT_PUBLIC_BASE_URLhttps://mado.shikumiai.com
NEXT_PUBLIC_SITE_BASE_URLhttps://mado.shikumiai.com
秘密の値はこの手順書に載せていません。 このページは共有できる形で置いてあるので、鍵はすべて手元の .env.local を見てください。 vercel.json に東京リージョン（hnd1）を指定済みなので、そちらの設定は不要です。
03

mado.shikumiai.com を繋ぐ

ここが通らないと 04 以降が進みません。

エックスサーバーに入れる DNS レコード
ホスト名  : mado
種別      : CNAME
内容      : cname.vercel-dns.com
TTL       : 3600
shikumiai.com 本体（エックスサーバー側）には触りません。 足すのは mado のサブドメイン1件だけなので、今そこに載っているものは無事です。 Vercel の画面に出る値が cname.vercel-dns.com と違っていたら、画面に出た方を使ってください。
04

OAuth 同意画面を公開する審査なしで通ります

03 で URL が実在してから。テストユーザー限定の状態を外します。

Google の審査は要りません。 Supabase のログインが使うのは openid / email / profile の3つだけで、 これは機密スコープに当たらないためです。項目を埋めて「アプリを公開」を押せば、その場で本番になります。 （もし審査を求める画面が出たら、そこで止めて連絡してください）
項目入れる値
アプリ名Mado
ユーザーサポートメールryoya112@gmail.com
アプリのホームページhttps://mado.shikumiai.com
プライバシーポリシーhttps://mado.shikumiai.com/privacy
利用規約https://mado.shikumiai.com/legal
承認済みドメインshikumiai.com
デベロッパーの連絡先ryoya112@gmail.com
プライバシーポリシーと利用規約のページはコードに既にあります （/privacy と /legal）。02〜03 が終わっていれば、この URL で開けます。
05

Google のクライアントを差し替えるいま止まっている所

Supabase に古いプロジェクトのクライアントが入ったままです。

いま食い違っています。 Supabase に入っているのは 193352583496-…（前のプロジェクトのもの）で、 テストユーザーを登録したのは新しい Mado プロジェクトの 1030602025638-… です。このままだとログインで弾かれます。
承認済みのリダイレクト URI
https://dralpswprcifzmgojgxu.supabase.co/auth/v1/callback
Supabase に入れる Client ID
1030602025638-tpgpqoc2u7civ1hvsvl65j2ta54m06bf.apps.googleusercontent.com
Client Secret はこのページに載せていません。ダウンロード済みの client_secret_1030602025638-….json を開いて、client_secret の値をコピーしてください。
06

Supabase 側の URL を本番に向ける

ここが localhost のままだと、ログイン後に本番へ戻れません。

Redirect URLs（2件とも入れる）
https://mado.shikumiai.com/**
http://localhost:3000/**
プロジェクト名を変えても、接続先の dralpswprcifzmgojgxu は変わりません。表示名だけなので影響ゼロです。
